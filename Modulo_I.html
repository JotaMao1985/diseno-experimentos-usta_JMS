Sección 1: Entorno de Trabajo y RMarkdown

1.1 Instalación y Configuración de R y RStudio

¿Qué es R?

R es un lenguaje de programación y un entorno de software libre especializado en análisis estadístico y visualización de datos. Fue creado por Ross Ihaka y Robert Gentleman en 1993 y desde entonces se ha convertido en el estándar de facto para la estadística y la ciencia de datos.

¿Qué es RStudio?

RStudio es un Entorno de Desarrollo Integrado (IDE) para R que facilita la escritura de código, la visualización de gráficos, la gestión de paquetes y la creación de documentos. Existen dos versiones principales:

  • RStudio Desktop: Versión local instalada en tu computador
  • RStudio Server: Versión web que se ejecuta en un servidor remoto

💡 Instalación

Paso 1: Descarga e instala R desde cran.r-project.org

Paso 2: Descarga e instala RStudio desde posit.co/download

Importante: Instala R primero, luego RStudio.

Interfaz de RStudio

La interfaz de RStudio se divide en cuatro paneles principales:

  1. Editor de código (arriba-izquierda): Donde escribes y guardas tus scripts
  2. Consola (abajo-izquierda): Donde se ejecuta el código y muestra resultados
  3. Entorno/Historial (arriba-derecha): Muestra objetos, variables y historial
  4. Archivos/Gráficos/Paquetes/Ayuda (abajo-derecha): Visualización de archivos, gráficos y documentación

⌨️ Atajos de Teclado Útiles

  • Ctrl + Enter - Ejecutar línea actual
  • Ctrl + Shift + Enter - Ejecutar script completo
  • Ctrl + 1 - Mover cursor al editor
  • Ctrl + 2 - Mover cursor a la consola
  • Ctrl + Shift + C - Comentar/Descomentar líneas
  • Ctrl + Shift + M - Insertar operador pipe (%>%)

Sección 2: Fundamentos de R

En esta sección aprenderás los conceptos fundamentales del lenguaje R: tipos de datos, vectores, estructuras avanzadas y cómo trabajar con datos reales.

2.1 Conceptos Básicos de R

Operaciones Aritméticas

R funciona como una calculadora avanzada. Puedes realizar operaciones matemáticas directamente en la consola:

# Operaciones básicas
5 + 3        # Suma: resultado 8
10 - 4       # Resta: resultado 6
6 * 7        # Multiplicación: resultado 42
20 / 4       # División: resultado 5
2^3          # Potencia: resultado 8
17 %% 5      # Módulo (resto): resultado 2
17 %/% 5     # División entera: resultado 3

Variables y Asignación

En R, usamos el operador <- (flecha) para asignar valores a variables. También puedes usar =, aunque <- es el estilo preferido en R:

# Asignación de variables
nombre <- "María"
edad <- 25
altura <- 1.65
es_estudiante <- TRUE

# Imprimir valores
print(nombre)
edad          # También se muestra al escribir solo el nombre

Tipos de Datos en R

Tipo Descripción Ejemplo
numeric Números decimales 3.14159, -42.5
integer Números enteros 42L, -7L
character Texto (cadenas) "Hola", 'R'
logical Valores booleanos TRUE, FALSE
factor Variables categóricas factor(c("A", "B", "A"))

Para verificar el tipo de dato de una variable, usa la función class():

x <- 42
class(x)      # "numeric"

y <- "Hola"
class(y)      # "character"

Vectores

El vector es la estructura de datos más básica en R. Es una colección de elementos del mismo tipo. Usamos la función c() (concatenar) para crear vectores: 

# Crear vectores
numeros <- c(1, 2, 3, 4, 5)
nombres <- c("Ana", "Luis", "Pedro")
logicos <- c(TRUE, FALSE, TRUE)

# Operaciones con vectores
numeros * 2           # Multiplica cada elemento por 2
length(numeros)       # Número de elementos: 5
numeros[3]            # Acceder al tercer elemento: 3
numeros[c(1, 3, 5)]   # Elementos 1, 3 y 5

💡 Secuencias Útiles

1:10                    # 1, 2, 3, ..., 10
seq(1, 10, by = 2)       # 1, 3, 5, 7, 9
rep(5, times = 3)       # 5, 5, 5
rep(c(1, 2), each = 2)  # 1, 1, 2, 2

1.3 Introducción a RMarkdown

¿Qué es RMarkdown?

RMarkdown es un formato de archivo que permite crear documentos dinámicos que combinan:

  • Texto con formato (usando sintaxis Markdown)
  • Código de R ejecutable
  • Resultados de código (tablas, gráficos, valores)

Un archivo .Rmd tiene tres componentes principales:

title: "Mi Primer Análisis"

2.2 Estructuras de Datos Avanzadas

Matrices

Las matrices son arreglos bidimensionales donde todos los elementos deben ser del mismo tipo: 

# Crear una matriz
matriz <- matrix(
  data = 1:12,
  nrow = 3,           # 3 filas
  ncol = 4,           # 4 columnas
  byrow = TRUE        # Llenar por filas
)

# Acceder a elementos
matriz[2, 3]         # Fila 2, columna 3
matriz[2, ]          # Toda la fila 2
matriz[, 3]          # Toda la columna 3

Data Frames

Los data frames son la estructura más importante para el análisis de datos. Son tablas donde cada columna puede tener un tipo de dato diferente:

# Crear un data frame
estudiantes <- data.frame(
  nombre = c("Ana", "Luis", "María"),
  edad = c(20, 22, 19),
  nota = c(85.5, 90.2, 78.9),
  aprobado = c(TRUE, TRUE, FALSE)
)

# Explorar el data frame
head(estudiantes)      # Primeras 6 filas
str(estudiantes)       # Estructura del objeto
summary(estudiantes)   # Resumen estadístico
dim(estudiantes)       # Dimensiones (filas, columnas)
names(estudiantes)     # Nombres de columnas

Listas

Las listas son colecciones que pueden contener elementos de diferentes tipos, incluyendo otros objetos:

# Crear una lista
mi_lista <- list(
  numeros = 1:5,
  texto = "Hola",
  matriz = matrix(1:4, nrow = 2),
  df = estudiantes
)

# Acceder a elementos de la lista
mi_lista$numeros       # Por nombre
mi_lista[[1]]         # Por índice
mi_lista[["texto"]]   # Por nombre con [[ ]]

⚠️ Diferencia entre [ ] y [[ ]]

En listas: [ ] devuelve una sublista, mientras que [[ ]] devuelve el elemento directamente.

mi_lista[1]           # Devuelve una lista con un elemento
mi_lista[[1]]          # Devuelve el vector directamente

Desde CSV

El formato CSV (Comma Separated Values) es uno de los más comunes:

datos <- read.csv("datos.csv")

datos <- read_csv("datos.csv")

3.2 Filtrado y Selección

Indexación en Data Frames

La indexación usa la sintaxis [filas, columnas]:

# Seleccionar columnas
estudiantes$nombre           # Una columna como vector
estudiantes[, "edad"]        # Una columna
estudiantes[, c("nombre", "nota")]  # Múltiples columnas

# Seleccionar filas
estudiantes[1:2, ]            # Primeras 2 filas
estudiantes[estudiantes$edad > 19, ]  # Filtrar por condición

# Combinar filas y columnas
estudiantes[estudiantes$nota >= 80, c("nombre", "nota")]

Funciones de Subconjunto

# Usando subset()
subset(estudiantes, edad > 19)
subset(estudiantes, nota >= 80, select = c(nombre, nota))

# Usando which()
estudiantes[which(estudiantes$nota == max(estudiantes$nota)), ]

Manejo de Datos Faltantes (NA)

# Detectar valores faltantes
is.na(datos)           # Matriz de TRUE/FALSE
anyNA(datos)          # ¿Hay algún NA?
sum(is.na(datos))     # Contar NAs

# Eliminar filas con NA
datos_completos <- na.omit(datos)

# Reemplazar NA
datos$edad[is.na(datos$edad)] <- mean(datos$edad, na.rm = TRUE)

# na.rm en funciones
mean(datos$valor, na.rm = TRUE)

Sección 4: Programación en R

Esta sección te enseñará a escribir código más eficiente y reutilizable mediante la creación de funciones personalizadas y el uso de estructuras de control de flujo.

4.1 Creación de Funciones

Sintaxis Básica

En R, las funciones se definen con function():

# Estructura básica
nombre_funcion <- function(argumentos) {
  # Cuerpo de la función
  return(resultado)
}

# Ejemplo: Calcular el área de un círculo
area_circulo <- function(radio) {
  area <- pi * radio^2
  return(area)
}

# Usar la función
area_circulo(5)    # Resultado: 78.53982

Argumentos y Valores por Defecto

# Función con múltiples argumentos
saludar <- function(nombre, saludo = "Hola") {
  paste(saludo, nombre, "!")
}

saludar("María")              # "Hola María !"
saludar("Juan", "Buenos días")  # "Buenos días Juan !"

# Argumentos con nombres
saludar(saludo = "Hi", nombre = "Ana")

Funciones con Condicionales

# Función con validación
descuento <- function(precio, porcentaje) {
  if (porcentaje < 0 | porcentaje > 100) {
    stop("El porcentaje debe estar entre 0 y 100")
  }
  precio * (1 - porcentaje/100)
}

💡 Buenas Prácticas

  • Usa nombres descriptivos para funciones (verbos)
  • Documenta tu función con comentarios
  • Valida los argumentos de entrada
  • Retorna resultados explícitamente con return()

4.2 Estructuras de Control

Condicionales: if, else, else if

# Estructura if simple
edad <- 20
if (edad >= 18) {
  print("Mayor de edad")
}

# if-else
if (edad >= 18) {
  print("Mayor de edad")
} else {
  print("Menor de edad")
}

# if-else if-else
calificacion <- 85
if (calificacion >= 90) {
  nota <- "A"
} else if (calificacion >= 80) {
  nota <- "B"
} else if (calificacion >= 70) {
  nota <- "C"
} else {
  nota <- "D"
}

ifelse() Vectorizado

Para operaciones vectorizadas, usa ifelse() en lugar de if-else:

edades <- c(15, 22, 17, 30, 16)
estado <- ifelse(edades >= 18, "Mayor", "Menor")
# Resultado: "Menor" "Mayor" "Menor" "Mayor" "Menor"

# ifelse anidado
categoria <- ifelse(edades < 13, "Niño",
                ifelse(edades < 20, "Adolescente", "Adulto"))

switch()

Útil cuando tienes múltiples condiciones basadas en un valor:

dia_numero <- 3
dia_nombre <- switch(as.character(dia_numero),
  "1" = "Lunes",
  "2" = "Martes",
  "3" = "Miércoles",
  "4" = "Jueves",
  "5" = "Viernes",
  "Fin de semana"
)

4.3 Loops y Apply

Bucle for

# Iterar sobre una secuencia
for (i in 1:5) {
  print(i)
}

# Iterar sobre un vector
nombres <- c("Ana", "Luis", "María")
for (nombre in nombres) {
  print(paste("Hola,", nombre))
}

# Iterar sobre filas de un data frame
for (i in 1:nrow(estudiantes)) {
  print(estudiantes$nombre[i])
}

Bucle while

contador <- 1
while (contador <= 5) {
  print(contador)
  contador <- contador + 1
}

Familia apply (Preferida en R)

En R, se prefiere usar funciones vectorizadas en lugar de loops explícitos:

# apply() - para matrices
matriz <- matrix(1:12, nrow = 3)
apply(matriz, 1, sum)    # Suma por filas (MARGIN = 1)
apply(matriz, 2, mean)  # Media por columnas (MARGIN = 2)

# lapply() - devuelve lista
mi_lista <- list(a = 1:5, b = 6:10)
lapply(mi_lista, sum)

# sapply() - simplifica el resultado
sapply(mi_lista, sum)    # Devuelve vector

# tapply() - aplicar por grupos
tapply(estudiantes$nota, estudiantes$aprobado, mean)

💡 Recomendación

En R moderno, se recomienda usar funciones del paquete purrr (tidyverse) en lugar de la familia apply:

library(purrr)
map(mi_lista, sum)       # Equivalente a lapply
map_dbl(mi_lista, sum)   # Devuelve vector numérico

Sección 3: Manipulación de Datos con dplyr

dplyr es el paquete más popular de R para la manipulación de datos. Proporciona una "gramática" coherente y eficiente para realizar las operaciones más comunes de data wrangling.

4.1 El Operador Pipe (%>%)

¿Qué es el Pipe?

El operador pipe %>% (del paquete magrittr) permite encadenar operaciones de izquierda a derecha, haciendo el código más legible:

# Sin pipe
sum(sqrt(abs(-10:10)))

# Con pipe
-10:10 %>%
  abs() %>%
  sqrt() %>%
  sum()

Uso con Data Frames

library(dplyr)

# Sin pipe
arrange(
  filter(
    select(estudiantes, nombre, nota),
    nota >= 80
  ),
  desc(nota)
)

# Con pipe (mucho más legible)
estudiantes %>%
  select(nombre, nota) %>%
  filter(nota >= 80) %>%
  arrange(desc(nota))

⌨️ Atajo en RStudio

Presiona Ctrl + Shift + M para insertar el operador pipe automáticamente.

3.4 Verbos de dplyr

select() - Seleccionar Columnas

# Seleccionar columnas específicas
estudiantes %>%
  select(nombre, edad)

# Excluir columnas
estudiantes %>%
  select(-aprobado)

# Selección con patrones
estudiantes %>%
  select(starts_with("n"))   # Columnas que empiezan con "n"

# Reordenar columnas
estudiantes %>%
  select(nota, nombre, everything())

filter() - Filtrar Filas

# Filtrar con una condición
estudiantes %>%
  filter(nota >= 80)

# Múltiples condiciones (AND)
estudiantes %>%
  filter(edad > 19, nota >= 80)

# Condiciones OR
estudiantes %>%
  filter(edad < 20 | nota >= 90)

# Filtrar valores en un vector
estudiantes %>%
  filter(nombre %in% c("Ana", "Luis"))

mutate() - Crear/Modificar Columnas

# Crear nueva columna
estudiantes %>%
  mutate(nota_100 = nota * 100 / 50)

# Múltiples columnas
estudiantes %>%
  mutate(
    nota_100 = nota * 2,
    categoria = ifelse(nota >= 80, "Alta", "Baja")
  )

# Usar columnas recién creadas
estudiantes %>%
  mutate(
    nota_100 = nota * 2,
    resultado = ifelse(nota_100 >= 160, "Aprobado", "Reprobado")
  )

arrange() - Ordenar Filas

# Orden ascendente
estudiantes %>%
  arrange(nota)

# Orden descendente
estudiantes %>%
  arrange(desc(nota))

# Ordenar por múltiples columnas
estudiantes %>%
  arrange(edad, desc(nota))

summarise() - Resumir Datos

# Estadísticas simples
estudiantes %>%
  summarise(
    promedio = mean(nota),
    maximo = max(nota),
    minimo = min(nota),
    total = n()   # Contar filas
  )

count() - Contar Observaciones

# Contar por categoría
estudiantes %>%
  count(aprobado)

# Con ordenamiento
estudiantes %>%
  count(aprobado, sort = TRUE)

3.5 Agrupación y Joins

group_by() - Agrupar Datos

La función group_by() cambia el comportamiento de las funciones posteriores para operar por grupos:

# Estadísticas por grupo
estudiantes %>%
  group_by(aprobado) %>%
  summarise(
    promedio = mean(nota),
    cantidad = n(),
    edad_promedio = mean(edad)
  )

# Operaciones por grupo con mutate
estudiantes %>%
  group_by(aprobado) %>%
  mutate(
    nota_relativa = nota - mean(nota)  # Desviación del grupo
  )

Joins (Combinar Data Frames)

# Data frames de ejemplo
estudiantes <- data.frame(
  id = 1:3,
  nombre = c("Ana", "Luis", "María")
)

calificaciones <- data.frame(
  id = c(1, 2, 4),
  nota = c(85, 90, 78)
)

# left_join: Mantiene todas las filas del primer data frame
left_join(estudiantes, calificaciones, by = "id")

# inner_join: Solo filas presentes en ambos
inner_join(estudiantes, calificaciones, by = "id")

# full_join: Todas las filas de ambos
full_join(estudiantes, calificaciones, by = "id")

📊 Tipos de Join

Función Descripción
left_join() Mantiene todas las filas de X
right_join() Mantiene todas las filas de Y
inner_join() Solo filas presentes en ambos
full_join() Todas las filas de ambos
anti_join() Filas de X que no están en Y

Pipeline Completo de Ejemplo

# Análisis completo con dplyr
estudiantes %>%
  # 1. Filtrar estudiantes activos
  filter(estado == "activo") %>%
  
  # 2. Calcular métricas por programa
  group_by(programa) %>%
  
  # 3. Crear resumen
  summarise(
    total = n(),
    promedio_nota = mean(nota_final, na.rm = TRUE),
    tasa_aprobacion = mean(aprobado) * 100,
    .groups = "drop"  # Desagrupar al final
  ) %>%
  
  # 4. Filtrar programas con suficientes estudiantes
  filter(total >= 10) %>%
  
  # 5. Ordenar por tasa de aprobación
  arrange(desc(tasa_aprobacion))

Sección 5: Visualización de Datos con ggplot2

La visualización de datos es fundamental en el análisis estadístico. ggplot2 es el paquete más popular de R para crear gráficos de alta calidad basado en la "Gramática de Gráficos" (Grammar of Graphics).

5.1 Fundamentos de ggplot2

¿Qué es ggplot2?

ggplot2 es un paquete del tidyverse que implementa la Gramática de Gráficos, un sistema para describir gráficos en capas. Su filosofía se basa en tres componentes principales:

🎯 Los 3 Componentes de ggplot2

  1. Datos: El data frame que contiene tu información
  2. Estéticas (aes): Cómo se mapean las variables a elementos visuales (ejes, colores, tamaños)
  3. Geometrías (geom): El tipo de gráfico (puntos, barras, líneas, etc.)

Sintaxis Básica

La estructura fundamental de cualquier gráfico con ggplot2 es:

library(ggplot2)

# Estructura base
ggplot(data = <DATA>) +
  <GEOM_FUNCTION>(mapping = aes(<MAPPINGS>))

# Ejemplo con dataset iris
ggplot(data = iris) +
  geom_point(mapping = aes(x = Sepal.Length, y = Petal.Length))

💡 Atajo en RStudio

Puedes usar el operador pipe con ggplot2 de forma natural:

iris %>%
  ggplot(aes(x = Sepal.Length, y = Petal.Length)) +
  geom_point()

Instalación

# Instalar el tidyverse completo (incluye ggplot2)
install.packages("tidyverse")

# O instalar solo ggplot2
install.packages("ggplot2")

# Cargar el paquete
library(ggplot2)

Capas y Personalización

Puedes agregar múltiples capas y personalizar cada aspecto del gráfico:

ggplot(data = iris, aes(x = Sepal.Length, y = Petal.Length)) +
  geom_point(aes(color = Species, size = Petal.Width)) +
  geom_smooth(method = "lm", color = "black") +
  labs(
    title = "Relación entre Sepal.Length y Petal.Length",
    subtitle = "Dataset Iris",
    x = "Sepal Length (cm)",
    y = "Petal Length (cm)",
    color = "Especie"
  ) +
  theme_minimal()

5.2 Tipos de Gráficos

Gráfico de Dispersión (Scatter Plot)

Ideal para explorar relaciones entre dos variables continuas:

# Scatter plot básico
ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width)) +
  geom_point(aes(color = Species)) +
  labs(title = "Sepal: Largo vs Ancho")

# Con transparencia (para muchos datos)
geom_point(alpha = 0.6)

# Con forma por grupo
geom_point(aes(shape = Species))

Gráfico de Barras

Para visualizar conteos o proporciones por categoría:

# Conteo automático por categoría
ggplot(iris, aes(x = Species)) +
  geom_bar(fill = "steelblue") +
  labs(title = "Conteo por Especie", y = "Cantidad")

# Barras con valores precalculados
resumen <- iris %>%
  group_by(Species) %>%
  summarise(promedio = mean(Sepal.Length))

ggplot(resumen, aes(x = Species, y = promedio)) +
  geom_col(fill = "coral") +
  labs(title = "Promedio de Sepal.Length por Especie")

Histograma

Para visualizar la distribución de una variable continua:

# Histograma básico
ggplot(iris, aes(x = Sepal.Length)) +
  geom_histogram(bins = 15, fill = "darkgreen", color = "white") +
  labs(title = "Distribución de Sepal.Length")

# Con densidad superpuesta
geom_histogram(aes(y = after_stat(density)), bins = 15) +
  geom_density(color = "red", size = 1)

# Por grupo (faceting)
ggplot(iris, aes(x = Sepal.Length)) +
  geom_histogram(bins = 10, fill = "purple") +
  facet_wrap(~Species, ncol = 1)

Diagrama de Caja (Boxplot)

Para comparar distribuciones entre grupos:

# Boxplot básico
ggplot(iris, aes(x = Species, y = Sepal.Length)) +
  geom_boxplot(aes(fill = Species)) +
  labs(title = "Sepal.Length por Especie") +
  theme(legend.position = "none")

# Con puntos individuales (jitter)
geom_boxplot(outlier.shape = NA) +
  geom_jitter(width = 0.2, alpha = 0.5)

Gráfico de Líneas

Para visualizar tendencias a lo largo del tiempo:

# Crear datos de ejemplo con fecha
datos_tiempo <- data.frame(
  fecha = seq.Date(as.Date("2026-01-01"), by = "month", length.out = 12),
  valor = c(10, 15, 13, 18, 22, 25, 23, 28, 30, 27, 32, 35)
)

ggplot(datos_tiempo, aes(x = fecha, y = valor)) +
  geom_line(color = "steelblue", size = 1.2) +
  geom_point(color = "darkred", size = 2) +
  labs(title = "Tendencia Mensual", x = "Fecha", y = "Valor")

Crear múltiples gráficos por subgrupos:

ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width)) +

  scale_color_gradient(low = "blue", high = "red")

# Faceting por dos variables
facet_grid(fila ~ columna)
