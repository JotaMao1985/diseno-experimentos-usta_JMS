# Diseño de Experimentos y Muestreo 📊

**Material de estudio interactivo para la Facultad de Estadística de la Universidad Santo Tomás**. 

Este repositorio contiene recursos académicos estructurados en un formato *Single Page Application* (SPA) modular. Cada documento integra elementos teóricos, fórmulas matemáticas (vía KaTeX), bloques de código resaltados con sintaxis real de desarrollo e interacciones didácticas para propiciar el aprendizaje de R y Python en el ámbito experimental.

## 🚀 Despliegue (Sitio Web)
El material puede visualizarse directamente a través de GitHub Pages en el siguiente enlace:
👉 **[Acceder al Material de Estudio](https://jotamao1985.github.io/diseno-experimentos-usta_JMS/)**

## 📚 Contenido del Proyecto

Esta colección se divide en módulos secuenciales:
1. **Clase de Repaso** (Conceptos fundamentales y terminología)
2. **Semana I: Introducción** (Estructuración de modelos)
3. **Idoneidad del Modelo** (Evaluación de supuestos paramétricos)
4. **Diseño DBCA** (Bloques Completos al Azar)
5. **Diseño DBIA** (Bloques Incompletos al Azar)
6. **Diseño DCL** (Cuadrados Latinos)
7. **Cuadrados de Youden** (Diseños balanceados latino-incompletos)
8. **Greco-Latinos (DCGL)** (Control avanzado multidimensional)
9. **Efectos Aleatorios** (Componentes de Varianza)
10. **Proyecto Investigativo** (Ejercicio integrador con *Grader Tool* embebido)

## 🛠️ Tecnologías Empleadas
- **Core:** HTML5, CSS Vanilla, JavaScript.
- **Estilos Visuales:** Tailwind CSS, adoptando los esquemas cromáticos institucionales de la Universidad Santo Tomás (USTA).
- **Herramientas de Renderizado:**
  - `React.js` y `Babel` (Renderizado de calculadoras, dashboards e interfaces interactivas como la rúbrica de calificación).
  - `KaTeX` (Renderizado acelerado de funciones matemáticas y látex).
  - `Highlight.js` (Resaltado de sintaxis emulando el tema Dark+ de Visual Studio Code).
